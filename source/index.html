Screen calibration

01

Use the width in dp of the screen when this screenshot was captured. In portrait, Developer options → Minimum width often matches it. Landscape and split screen need the actual captured width.

Cropping alone keeps pixels the same size. If the crop was resized, enter the full screenshot width multiplied by that same resize factor.

Minimum width 384dp is not 384 DPI. This browser’s pixel ratio is not the screenshot’s density.

Half size = 0.5. A crop with no resizing stays at 1. Stretched images need an undistorted source.
